Week 3 — Multiplayer & Events A single-player Snake & Ladder game is a solitaire puzzle. The real game is multiplayer — taking turns, watching opponents climb ladders, celebrating when a snake bites someone ahead of you. This week you add a second player, implement turn rotation, and wire CAP events so the game state advances automatically.
